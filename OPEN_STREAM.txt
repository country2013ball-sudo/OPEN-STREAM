6. DAILY FREE VIEWING LIMIT

Every free account receives 60 minutes of authorized playback per calendar day, using the Asia/Kolkata timezone by default.

Requirements:

1. Show a visible daily usage meter, such as 23 of 60 minutes used.
2. Calculate usage from server-validated playback sessions, not only from a local Android timer.
3. Track actual playback time rather than time spent browsing.
4. Pause counting when the video is paused, stopped, or no longer playing.
5. Handle background playback consistently with the app's playback rules.
6. Prevent simple clock changes, application reinstalls, or clearing local data from resetting the allowance.
7. Handle multiple devices using one shared account allowance.
8. Use server timestamps and idempotent session updates.
9. Apply an explicit policy for midnight rollover and sessions that cross midnight.
10. Warn users before they reach the limit.
11. When the limit is reached, pause playback and display the available membership plans.
12. Reset the allowance according to the documented calendar-day policy.
13. Keep account-level usage records while minimizing the personal data stored.
14. Do not falsely claim that a timer can perfectly verify playback if the selected external provider does not expose the necessary playback information.

Use server-side entitlement checks and signed, short-lived playback-session tokens for media served by our own authorized streaming backend.

External provider playback must respect that provider's own access controls and integration requirements.
